# 使用指南

[返回项目首页](../README.md)

## 开始记录

在侧栏创建笔记本和笔记，点击笔记即可编辑。新笔记库会初始化“开始使用”“工作与计划”“学习与记录”等示例；不会覆盖已有内容，清空后也不会重复生成。

笔记本支持嵌套，可重命名、移动、设置图标和调整顺序。常用笔记可加入收藏；同时查看多篇内容时，可使用标签页、分屏或独立窗口。

## 编辑与显示

默认使用实时预览，在输入 Markdown 时显示排版效果。可以通过工具栏、右键菜单或斜杠指令插入内容，也可以直接输入 Markdown。

在笔记右上角“更多”菜单中选择阅读或源码模式，再次切换可返回实时预览。阅读模式禁止修改正文和表格；源码模式显示 Markdown 标记。

支持标题、列表、任务、引用、代码高亮、表格、图片、行内及块级公式。设置中可调整浅色／深色外观、编辑器主题和字号。

### Markdown 兼容性

普通 Markdown 正文可使用其他编辑器打开。部分排版使用扩展语法、HTML 或元数据，例如表格合并与尺寸、图片裁剪、高亮块、文字颜色和对齐。其他工具可能只显示其中一部分；需要交付给其他工具时，建议先检查导出效果。

## 列表与搜索

笔记列表右上角提供手动顺序、创建时间、更新时间和名称排序。时间支持从新到旧／从旧到新，名称支持升序／降序；排序偏好会记住。

列表同时显示“创建时间”和“更新时间”，按本机时区显示到秒：

- 创建时间取自本地笔记目录的文件系统创建时间；复制、导入或迁移后可能变化，不能视为原作者最初写作时间。
- 更新时间取自 Markdown 正文文件的修改时间，不等同于笔记本排序或图标等设置的修改时间。

“全部笔记”包含嵌套笔记；进入某个笔记本时，列表也包含其下级笔记本中的笔记。全文搜索覆盖标题、路径和正文，并包含当前窗口未保存的草稿，最多返回 500 篇匹配结果。

## 自动保存与恢复

输入后约 600 毫秒触发自动保存。切换笔记、关闭标签或正常退出前会等待保存完成；保存失败时保留草稿并阻止相应操作。

应用定期检查磁盘上的外部修改，并在窗口重新获得焦点时检查。没有未保存编辑的笔记会自动刷新；存在冲突时，可重试、另存副本，或放弃草稿使用磁盘版本。另存副本适合希望保留双方内容的情况。

历史版本可用于查看和恢复旧内容。删除的笔记先进入回收站，可恢复或彻底删除。清空回收站、强制结束进程和磁盘故障不同于正常退出；自动保存与草稿恢复不能替代备份。

## 导入导出与备份

在设置的“导入、导出与备份”区域进行 Markdown 导入、导出和笔记库备份恢复。

| 操作 | 包含内容 | 适合场景 |
| --- | --- | --- |
| 导入 Markdown | `.md` / `.markdown` 文件或文件夹，以及可访问的本地图片 | 导入其他工具中的笔记 |
| 导出全部 Markdown | 正文、笔记本层级和图片附件 | 迁移到其他 Markdown 工具 |
| `.mnebackup` 备份 | 已保存笔记、附件、图标与排序、历史版本和回收站 | 完整笔记库备份与迁移 |
| 当前笔记 PDF | 当前笔记的排版结果；仅 macOS | 阅读、打印和分享 |

Markdown 导出不包含历史版本和回收站。完整备份不包含外观与工作区显示偏好，备份文件未加密。

### 导入图片与文件夹

Markdown 导入会复制内联或引用式本地图片到笔记附件目录，并更新引用。图片必须在所选文件夹内；导入单文件时，以文件所在目录为范围。图片缺失或引用越界时，整次导入会失败，请修正来源后重试。网络图片保留原地址，不会在 Markdown 导入时自动下载。

导出和备份请选择应用数据目录之外、尚不存在的目标位置。单次数据操作限制为 256 MB，单次导入最多 10,000 篇笔记，备份最多 50,000 个条目。

### 恢复备份

恢复会创建新的“恢复 日期”笔记本分组，不覆盖已有笔记；备份中的回收站条目也会恢复并重新分配标识。备份使用逐文件 SHA-256 校验，损坏的备份会被拒绝。

### 导出 PDF

macOS 中使用“更多 → 导出 → 当前笔记 PDF”。应用先保存当前草稿，再生成按 A4 分页的完整文档；请选择尚不存在的目标文件。图片加载失败会报错，复杂表格和嵌套内容建议导出后复核。

PDF 是排版文件，不是可编辑的笔记库备份。Windows 当前不支持直接导出 PDF。

## 本地文件与偏好

默认笔记位置见 [项目首页](../README.md#笔记保存在哪里)。设置可打开存储目录。项目不会自动读取或迁移原 MeteorNote 应用的数据。

一篇笔记通常包含以下内容：

```text
笔记名称/
├── 笔记名称.md
├── assets/          # 图片附件
├── versions/        # 历史版本
└── .note.json       # 笔记元数据
```

笔记本使用 `.notebook.json` 和 `.order.json` 保存图标与顺序。手动复制文件时，仅复制 `.md` 可能遗漏附件；完整迁移建议使用备份功能。

显示偏好保存在应用 WebView 的本地存储中。设置中的工作区名称和 Logo 只改变侧栏显示，不改变应用名称、Dock 图标或笔记存储目录。名称支持 1–32 字；Logo 图片不超过 5 MB，会转换为最长边 256px 的 PNG 并本地保存。

## 常见问题

**需要联网或登录吗？**

日常本地笔记操作不需要账号或服务端。依赖安装、网络图片和外部链接可能需要联网。

**为什么在普通浏览器中打开开发地址不能读写笔记？**

当前产品是 Tauri 桌面应用，文件读写由原生端提供。浏览器测试页使用隔离数据，仅用于开发验证。

**可以直接作为网页编辑器嵌入其他项目吗？**

目前没有发布可直接嵌入的编辑器包或稳定的嵌入 API，需要先拆分编辑器与桌面文件操作。源码采用 MIT 许可证，可在遵守许可证的前提下复用。
