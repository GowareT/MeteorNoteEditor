# 每周计划

## 本周重点

本周希望完成一件可以验证结果的事：整理一个小型项目，从目标、执行到复盘留下完整记录。

| 优先级 | 事项 | 完成标准 |
| --- | --- | --- |
| 高 | 明确项目目标 | 一句话说清解决的问题 |
| 中 | 收集关键资料 | 留下三条可靠来源 |
| 中 | 完成第一个版本 | 能独立演示主要流程 |

## 行动清单

- [ ] 周一：明确目标与边界
- [ ] 周二：准备资料和示例
- [ ] 周三：完成第一版
- [ ] 周四：验证问题并调整
- [ ] 周五：回顾结果与下一步
