# 项目简报

## 背景与目标

示例项目：整理一套可持续使用的个人资料库，让常用资料能在一分钟内找到。

成功标准不是收集了多少内容，而是需要时能找到、看懂并使用它。

## 范围

- 本次包含：资料分类、命名规则、重点摘要和备份
- 本次不包含：一次性整理所有旧文件

## 里程碑

| 阶段 | 交付内容 | 状态 |
| --- | --- | --- |
| 准备 | 选出最常用的十份资料 | 进行中 |
| 整理 | 每份资料补充摘要与来源 | 待开始 |
| 验证 | 用三个真实问题测试搜索 | 待开始 |

## 风险与决策

> [!note:#fff6d6:lightbulb] 如果分类需要反复犹豫，先减少分类数量。整理规则应该帮助查找，而不是增加负担。

**当前决定：** 先完成一个小范围样本，再决定是否扩展。

**决定理由：** 用真实使用结果检查规则，比一开始设计很多层级更可靠。
