# 从这里开始

欢迎来到你的本地笔记空间。

这里准备了三组可以直接修改的笔记：开始使用、工作与计划、学习与记录。示例内容不是只读说明，你可以修改、移动或删除它们，把这个空间变成自己的。

## 写下第一条记录

不必先想好分类。先记下一句话、一个问题，或今天最重要的一件事，再慢慢整理。

- [ ] 新建一篇笔记，记录今天的想法
- [ ] 给笔记起一个方便以后搜索的标题
- [ ] 把它放进合适的笔记本
- [ ] 尝试搜索正文里的一句话

## 这份笔记库里有什么

| 笔记本 | 内容 | 适合什么时候打开 |
| --- | --- | --- |
| 开始使用 | 编辑示例、图片与公式、保存与备份 | 熟悉编辑器和整理资料 |
| 工作与计划 | 每周计划、项目简报、会议记录 | 安排工作和跟进进展 |
| 学习与记录 | 阅读笔记、问题清单、每日复盘 | 积累知识和回顾生活 |

## 安心整理

修改会自动保存。删除的笔记和笔记本先进入回收站，误删后可以恢复；重要内容也可以从历史版本中找回。

> [!note:#e8f2ff:lightbulb] 本地保存不等于异地备份。重要笔记建议定期备份到另一个磁盘。

你可以在设置中修改左上角的名称和 Logo。这只改变自己的工作区显示，不会改动笔记文件或存储位置。
