# 编辑与排版示例

这篇笔记展示常用格式。可以直接点进文字中修改，也可以选中文字后使用顶部工具栏。

## 常用文字格式

普通正文适合记录细节，**粗体**强调重点，*斜体*区分术语，***粗体与斜体***可以一起使用。

<u>下划线用于特别标记</u>，~~删除线表示不再采用的内容~~。下划线和删除线在工具栏中互斥。

用 ==高亮== 标出需要回看的词，也可以使用 <span style="color:#d14b35">文字颜色</span> 或 <mark style="background-color:#dff4c7">背景颜色</mark>。

2. 整理证据，找出不确定的地方
3. 决定下一步，并记录结果

## 引用与高亮块

> 好的记录不必面面俱到，但应让未来的自己看懂当时为什么做出这个决定。

> [!note:#fff6d6:lightbulb] **值得注意：** 行内高亮用于几个词，高亮块用于一整段重要信息。

## Markdown 写法

在段落开头输入井号再加空格，就能创建标题。输入列表标记再加空格，可以创建列表。输入代码围栏可以创建代码块。

空白正文里输入 / 可以选择插入内容；左侧工具栏也有插入入口。更多菜单保留阅读、源码、历史和导入导出功能。
