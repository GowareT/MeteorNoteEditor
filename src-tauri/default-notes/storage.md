# 保存、导入与备份

## 自动保存

编辑会在短暂延迟后保存。底部信息栏会显示保存状态；关闭窗口、退出应用或切换笔记时，会先尝试保存未完成的修改。

如果保存失败，不要急着关闭应用。先查看提示，可以重试，或把草稿另存为副本。强制结束进程无法保证退出保存完成。

## 其他软件修改了文件

编辑器会定期检查已打开的笔记。没有未保存内容时会刷新；本地草稿与磁盘内容冲突时，会保留草稿并提示选择，不直接覆盖。

## 导入与导出

更多菜单可以导入 Markdown 文件或整个文件夹。导入时会复制所选目录范围内的本地图片，原文件保持不变。

导出当前笔记会得到 Markdown 文件及其本地图片；导出 PDF 适合分享和打印，但不能代替可继续编辑的源文件备份。

| 方式 | 用途 | 包含内容 |
| --- | --- | --- |
| Markdown 导出 | 迁移到其他编辑器 | 正文和本地图片 |
| PDF 导出 | 分享、阅读、打印 | 当前笔记的排版内容 |
| 笔记库备份 | 完整数据保护 | 笔记、图片、历史及回收站 |

## 做一次备份

1. 打开设置，选择备份笔记库
2. 保存到笔记库以外的位置，最好是另一块磁盘
3. 检查备份文件是否已经生成
4. 重要修改后保留一个新的备份版本

恢复备份时会创建新的笔记本分组，不覆盖现有内容。单次操作最多支持 256 MB；备份文件未加密，请妥善保存。

## 误删与历史

回收站可以恢复删除的笔记或笔记本。彻底删除和清空回收站无法通过回收站撤销。单篇笔记的历史适合找回旧内容，但不能替代整个笔记库的备份。
