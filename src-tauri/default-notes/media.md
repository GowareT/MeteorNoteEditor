# 图片、公式与资料

把截图、图示和公式放在文字旁边，通常比单纯堆积链接更容易理解。

## 本地图片示例

下面这张图片随示例笔记一起保存在 assets 文件夹中，不依赖网络。

![MeteorNoteEditor 标识|96](assets/editor-logo.png)

插入本地图片时，编辑器会把图片存入当前笔记的附件目录。之后可以选中图片调整宽度、位置或裁剪区域。

网络图片使用原来的图片地址。导出 PDF 时需要能正常加载；长期保存的资料更适合使用本地图片。

## 公式示例

行内公式可以嵌入句子，例如圆的面积为 $A=\pi r^2$。

独立公式适合展示推导或结论：

$$
\frac{1}{n}\sum_{i=1}^{n}x_i
$$

记录公式时，也写下变量的含义。上式中，$n$ 是样本数，$x_i$ 是第 $i$ 个观测值。

## 资料记录模板

| 字段 | 记录 |
| --- | --- |
| 来源 | 书名、文章标题或网页链接 |
| 关键结论 | 用自己的话概括 |
| 适用条件 | 这个结论成立的前提 |
| 待核实 | 暂时没有足够证据的部分 |

> [!note:#e6f4ea:book-open] 图片和公式帮助理解，文字说明帮助日后检索。两者一起留下，资料才更容易复用。
